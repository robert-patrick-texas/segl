# Test plan

P0 is done when every row below has been run and recorded in `draft2/STATUS.md`, with the command, the environment, and the result. `scripts/testplan.py` runs every row but T-017, T-018, and T-021 as one command and prints one line for each. The dev container runs it (T11, `DEVELOPMENT.md`). T10b added T-019 and T-020 after the list was numbered, so they follow T-018. T02 and T03 cover the rows that pytest can reach without a browser. T-017 is a command of its own, `deploy/debian/package-test.sh`, which builds the `.deb` and installs it (T12). The same command runs T-021, the update, on the package it installed. T-021 was added after T12, at the user's request, so it follows T-020. T-022, the first row of P1's network objects, came with T15. T-023, history that lasts and clearing a slot, came with T16.

| T-022 | N-001 to N-005 | Network objects on a canvas. segl's library in the editor's library panel holds 12 devices and 5 links, and each one placed gets an `objectId` of its own. | T-023 | S-005, S-020 | History that lasts, and clearing a slot. On a clock the test sets, a slot written once a second for two hours keeps the newest 50 and exactly the revisions the minute, hour, and day tiers name. A flush that leaves fewer than 90% of the live elements keeps the board before it, which outlasts two more hours of drawing and is gone after a week. A flush that leaves 90% keeps nothing more. A restore and an import keep the board they replaced. The 21st kept revision drops the oldest kept one. A database from 0.5.0 migrates and reads back the same. `segl slot clear` removes the scene, the title, the revisions, and the file rows, keeps the image files another slot names, and raises the epoch. It refuses a slot outside 1–9, waits for the typed number unless `--yes` is given, stops and starts the unit with the package's settings, and refuses while segl answers on its port without them. `tests/test_retention.py` and `tests/test_clear.py` run these. `web/e2e/lasting.spec.ts` deletes a board, draws past the count (5 on its own server, where a site keeps 50), finds `Before delete` in History, restores it, and sees the board in both browsers. | T-024 | S-001, S-003, D-001 to D-005 | Diagram mode on slot 9. A reload, and a server killed and started again, keep the diagram. A browser without a pass sees the other's changes, has no pen to take, changes nothing, and its socket is refused `view_only`. At a host root and under `/board/`, nothing leaves the origin, no response sets a cookie, the socket is under the mount, drawio keeps one `localStorage` key of its own, and no service worker is registered. `tests/test_diagram.py` holds the server's rules: patch numbering and order, the copy rule, `saved`, the gate, `pen_held`, the size limit, the restart, and migration `0004`. `web/e2e/diagram.spec.ts`, and one test each in `durability.spec.ts` and `access.spec.ts`, run it in a browser. |

Preliminary sizes, as targets for a fixture rather than a tuning project: 2 concurrent editors on one slot is the gate; 10 is the stretch case to try once during T11 and record, not to block the gate. A 1,000-element fixture should still load and sync. Do not spend the MVP on horizontal scaling.

`npm --prefix web run stretch` runs both sizes and prints what it measured: ten editors on one slot, and a slot of 1,024 elements (`DEVELOPMENT.md`, size runs). It is not part of the gate. T11 ran it once in the dev container, and `draft2/STATUS.md` has the numbers.
